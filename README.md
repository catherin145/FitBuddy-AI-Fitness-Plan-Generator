# FitBuddy - AI Fitness Plan Generator

## About the Project

FitBuddy is an AI-powered web application that generates personalized fitness and general wellbeing plans based on user details.

The application uses AI to provide a suitable fitness plan according to the user's requirements and preferences.

## Features

- Personalized fitness plan generation
- AI-powered recommendations
- User-friendly web interface
- Fitness and wellbeing suggestions
- Feedback-based plan improvement
- User data storage
- View submitted user details

## Technologies Used

- Python
- FastAPI
- Gemini AI
- SQLite
- HTML
- CSS
- Jinja2 Templates
